# Учебная практика: Информационные системы (C++)

## О проекте
Данный репозиторий содержит материалы учебной практики (25.05.2026 - 30.05.2026). Студент: Шакир Нурасыл. 
В ходе практики решались задачи на языке программирования C++, начиная от базового ввода/вывода и заканчивая работой с массивами, циклами и функциями.

## Структура репозитория
- `1 день/` - исходные коды программ (C++) за первый день.
- `2 день/` - исходные коды программ (C++) за второй день.
- `3 день/` - исходные коды программ (C++) за третий день (циклы).
- `4 день/` - исходные коды программ (C++) за четвертый день (массивы и функции).
- `практика нурасыла 67 копия/` - исходные документы (`.docx`).
- `*.pdf` - отчёты по каждому дню, дневники практики и финальный отчёт.

## Что было сделано (Журнал изменений AI)
В рамках автоматизации и структурирования проекта было выполнено следующее:
1. **Конвертация документов**: Все файлы отчётов и дневников в формате `.docx` (3, 4, 5 дни и финальный отчёт) были сконвертированы в формат `.pdf` с использованием COM-объектов MS Word через PowerShell.
2. **Извлечение кода**: Из текстовых отчётов за 3 и 4 дни (Тема 9-12) был автоматически извлечен весь C++ код.
3. **Структурирование**: Созданы папки `3 день` и `4 день`, в которые помещены извлеченные скрипты. Файлы были автоматически названы в соответствии с заданиями (например, `01_последовательность_чисел.cpp`, `02_четные_числа.cpp` и т.д.).
4. **Документирование**: Создан этот файл `README.md` для сохранения контекста проекта, описания его структуры и проделанной работы.

## План на будущее (для понимания контекста)
- Если добавятся новые дни или задания (например, 5 день с кодом), код также нужно будет извлечь по аналогии с 3 и 4 днями.
